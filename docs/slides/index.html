Motivation

LM agents as scientists and diagnosticians

  • The promise: LM agents are being deployed for scientific discovery, medical diagnosis, and agentic coding — domains that require forming hypotheses, gathering information, and acting under uncertainty.
  • The evaluation gap: Real-world discovery is hard to benchmark — LMs already have strong priors about many domains, and high-profile results are difficult to verify and reproduce.
  • What we need: Controlled settings where we can formalize what “rational” means and directly compare LM behavior against human and ideal baselines.
  • Core tension: LMs are trained to answer questions — but discovery requires asking them. Can they do both?
Many exciting applications of LM agents involve scientific discovery and diagnosis. But evaluating these abilities is hard because LMs already know a lot about the real world. We need controlled environments where we can formalize rationality. And here's the key tension: LMs are trained to answer, not to ask.

Framework

Expected Information Gain

How much does the answer to this question tell us about the hidden board?

$$\text{EIG}_\varepsilon(q \mid x, \mathcal{H}_{1:t}) \;=\; \text{H}_b\!\big(\varepsilon + (1-2\varepsilon)\,p_t\big) \;-\; \text{H}_b(\varepsilon)$$

$p_t$ = probability the true answer is “yes” under current belief  ·  $\varepsilon$ = Spotter noise rate  ·  $\text{H}_b$ = binary entropy

Intuition: EIG is maximized when the question is most uncertain ($p_t \approx 0.5$) — i.e., when the answer will be most surprising and thus most informative. Questions with $p_t \approx 0$ or $p_t \approx 1$ have low EIG because we already know the answer.

Because questions are Python programs, we can execute them against sampled boards to compute EIG exactly. The key intuition: the most informative questions are the most uncertain ones — where samples split roughly 50/50 between yes and no.

Human Study

How do people play Collaborative Battleship?

N=42 participants · 126 game trajectories · BattleshipQA dataset

Key insight: Humans are resource-rational, not Bayes-optimal — they ask useful questions and make well-informed guesses, but don't exhaustively optimize. This is the right target for AI agents.

We ran a behavioral study with 42 participants. Two key findings: asking more questions leads to better performance, and people show diverse strategies. Importantly, humans are resource-rational, not Bayes-optimal.

SpotterQA

Grounding questions by generating code

Captain Are at least two of the four ships located entirely within columns 1–4?
Spotter (thinking) Let me translate this to code and execute it against the board…
Spotter Yes

Key idea: Translating to code grounds the answer in the actual board state, avoiding hallucination and misinterpretation.


def answer(true_board, partial_board) -> bool:
    # Columns 1-4 = zero-based indices 0-3
    max_allowed_col = 3
    ship_ids = [s for s in np.unique(true_board) if s > 0]

    count_within = 0
    for sid in ship_ids:
        cols = np.where(true_board == sid)[1]
        if cols.size > 0 and cols.max() <= max_allowed_col:
            count_within += 1

    return count_within >= 2

# >>> answer(true_board, partial_board)
# True
Here's a concrete example. The Captain asks whether at least two ships are in columns 1-4. The Spotter translates this into Python, executes it against the true board, and returns Yes. You can step through the code: first we set up, then iterate over ships checking column bounds, and finally return the boolean. This grounds reasoning in the actual board state.
Results

Code generation closes the gap to human performance

Three key findings. First, accuracy varies widely across models. Second, code generation consistently improves accuracy by 14.7 points. Third, and importantly, LMs struggle with context-dependent questions where humans remain consistent. Code helps but doesn't fully solve pragmatic grounding.
Method

Monte Carlo inference with a world model

Sample plausible boards consistent with observations, then marginalize to get a tile-level belief.

Before I show the strategies, here's the key building block: a world model. We sample plausible board configurations consistent with everything observed so far, using Sequential Monte Carlo. Marginalizing over these samples gives us a belief state.
Method

Three Bayesian strategies for rational agents

Belief-aware policies: what to ask, where to shoot, and when to explore vs. act.

 InfoMax Questions

$Q_{\text{Bayes}}$

Sample candidate questions from the LM, translate each to code, and select the one with the highest EIG under the current belief.

$q_t^{\star} \in \arg\max_{q \in \mathcal{Q}} \text{EIG}_\varepsilon(q \mid x, \mathcal{H}_{1:t})$

 Precision Moves

$M_{\text{Bayes}}$

Fire at the unrevealed tile with the highest posterior probability of containing a ship (MAP action over the belief).

$u_t^{\star} \in \arg\max_{u} \; p_t^{\text{hit}}(u \mid x, \mathcal{H}_{1:t})$

 Explore vs. Act

$D_{\text{Bayes}}$

One-step lookahead: ask when the post-question hit probability exceeds the current best shot, discounted by $\gamma$.

Ask $q_t^{\star}$ if $\;\gamma \, \hat{p}_{t+1}^{\text{hit}}(q_t^{\star}) > p_t^{\text{hit}}(u_t^{\star})$
We introduce three strategies that build on the belief state. Q-Bayes selects the most informative question by sampling candidates and picking the highest EIG. M-Bayes selects the best shot by computing the MAP hit probability. D-Bayes decides whether to ask or shoot via a one-step lookahead.

Generalization

Beyond Battleship: Guess Who?

  • Guess Who? from TextArena: richer object-relational semantics (age, clothing, facial hair, etc.)
  • Same Bayesian strategies, different domain
  • GPT-4o: 0.617 → 0.900 success rate
  • Llama-4-Scout: 0.300 → 0.724
  • Not Battleship-specific — generalizes to information-seeking games with combinatorial hypothesis spaces
To show these aren't Battleship-specific tricks, we replicate on Guess Who? from TextArena. Same strategies, similar gains. This generalizes to any domain where you need to narrow down a combinatorial hypothesis space through questions.

Takeaways

 Necessary but not sufficient

Good performance on controlled tasks like Battleship is a prerequisite for real-world discovery. If an agent can't explore rationally here, we shouldn't trust it in the clinic or the lab.

 Formalizing rationality

In science and medicine, we need to define and measure what rational exploration looks like. Environments like this let us compare LM behavior against human and ideal Bayesian baselines.

 World models as tools

Our symbolic world model is an interactive simulator: the agent tests hypotheses by running programs against sampled possible worlds. This connects to sandboxed coding environments, dynamic world models (e.g., Genie), and other forms of thinking before acting.

 From games to the real world

The same principles — asking informative questions, acting on evidence, balancing exploration and exploitation — apply to agentic coding, medical diagnosis, scientific discovery, and beyond.

Four takeaways. First, this is necessary but not sufficient for real-world discovery. Second, we need environments that let us formalize and measure rationality. Third, the world model here is essentially an interactive simulator, connecting to broader trends like sandboxed coding environments and dynamic world models. And fourth, these principles apply directly to agentic coding, diagnosis, and discovery.
