Motivation

AI agents for discovery

  • The promise: Many high-stakes applications of AI require seeking information.
  • The evaluation gap: Real-world discovery is hard to benchmark.
    • LMs already have strong priors about many domains.
    • Running experiments is time-consuming and expensive.
  • This work: Introduces a new framework for building and evaluating rational agents in controlled settings.
Some of the most exciting applications of AI today require agents to seek information strategically. Given limited resources, do language models behave like rational agents? And how do they compare to human scientists, doctors, or engineers? Studying these questions is difficult because LMs already know a lot about the real world. Moreover, running experiments is often time-consuming and expensive, so high-profile results can be difficult to verify and reproduce.

Challenges
Computing EIG exactly is intractable — three key difficulties:
Marginalization
Entropy requires marginalizing over combinatorial $s \in \mathcal{S}$.
Simulation
Estimating likelihood of outcome $y$ requires simulating experiment $x$.
Proposing experiments
Experiment space $X$ may be vast or open-ended.
Three key challenges make EIG hard to compute exactly. First, marginalization: evaluating the posterior requires summing over all possible structures. Second, simulation: the likelihood requires running experiments on hypothesized structures. Third, proposing experiments: the space of possible experiments may be too large to enumerate.

Inference-scaling for experiment design: more compute at decision time → better experiments → more efficient discovery.
Our approach equips an agent with a world model — a code-based simulator that encodes knowledge about the dynamics of the domain. The world model provides two affordances: 1. Sampling: The world model defines a generative process p(S). The agent uses it to sample candidate hypotheses consistent with observed evidence, forming a hypothesis space. 2. Simulation: The world model exposes functional operations (like an API) that can be composed to form experiments. The agent proposes experiments x, translates them into code f_x(·), then submits them to the world model to predict likely outcomes and compute EIG. Key insight: This affords an inference-scaling approach to experiment design. By proposing and scoring multiple experiments, the agent picks the ones that yield the most information. Our hypothesis is that this leads to more efficient discovery than baseline LLMs.
Approach

Building a sandbox for discovery

  • Minimal but complete. Simple state representation and dynamics, yet instantiates the full BED loop. No domain expertise required.
  • Human-interactive. Both humans and AI agents can play, enabling direct behavioral comparison.
  • Simulatable. Experiments take seconds, not days — outcomes can be generated automatically.
  • Measurable. We can quantify not just outcomes, but intermediate decisions: explore vs. exploit, and the value of information (EIG).

ARC-AGI 2 (Chollet et al., 2025): Inspiration for a challenging domain with a minimal state representation

We set out to build a suitable environment for evaluating discovery agents. We had several key desiderata. First, minimal but complete: the task should instantiate the full BED loop, with simple state representation and dynamics, no complex prompting to explain the rules. We drew inspiration from ARC-AGI, which shows that minimal domains can still be deeply challenging. Second, human-interactive: both humans and AI agents should be able to interact with the environment so we can compare behavior directly. Third, simulatable: experiments should take seconds, not days. Finally, measurable: we want to quantify not just final outcomes, but intermediate decisions — explore vs. exploit, and the information value of each question.

What can we study with this framework?

EIG lets us formalize key behavioral questions about humans and AI agents

 Asking & Answering

Do agents and humans ask informative questions? Do they provide accurate answers?

 Targeted Guessing

Do they make targeted guesses under uncertainty, integrating information from answers?

 Resource Rationality

Do they make effective use of available questions under a limited resource budget?

With the EIG framework in place, we can now formalize several key behavioral questions. First, do agents and humans ask informative questions and give accurate answers? Second, do they integrate information to make targeted guesses? Third, do they use their limited question budget effectively? These are the questions we'll investigate in our experiments.

Takeaways

 Necessary but not sufficient

Good performance on controlled tasks like Battleship is a prerequisite for real-world discovery. If an agent can't explore rationally here, we shouldn't trust it in the clinic or the lab.

 Formalizing rationality

In science and medicine, we need to define and measure what rational exploration looks like. Environments like this let us compare LM behavior against human and ideal Bayesian baselines.

 World models as tools

Our symbolic world model is an interactive simulator: the agent tests hypotheses by running programs against sampled possible worlds. This connects to sandboxed coding environments, dynamic world models (e.g., Genie), and other forms of thinking before acting.

 From games to the real world

The same principles — asking informative questions, acting on evidence, balancing exploration and exploitation — apply to agentic coding, medical diagnosis, scientific discovery, and beyond.

Four takeaways. First, this is necessary but not sufficient for real-world discovery. Second, we need environments that let us formalize and measure rationality. Third, the world model here is essentially an interactive simulator, connecting to broader trends like sandboxed coding environments and dynamic world models. And fourth, these principles apply directly to agentic coding, diagnosis, and discovery.

Why Battleship?

  • Combinatorial complexity. Battleship has a simple representation but a large state space, similar to other challenging text- and grid-based tasks like ARC.
  • Minimal closed-loop BED. Battleship instantiates the full Bayesian Experimental Design loop: agents form beliefs, design experiments (questions), observe outcomes, and update.
  • Formalizing rationality. We can quantify the value of each question using Expected Information Gain (EIG), enabling direct comparison between human and LM behavior.

ARC-AGI 2, Chollet et al., 2025

Why Battleship and not some other task? Three reasons. First, unlike ARC or open-ended benchmarks, Battleship has a fully formalized state space with optimal baselines — we can measure degrees of rationality, not just success or failure. Second, it's a minimal instance of closed-loop Bayesian experimental design. Third, we can formalize what a "good question" is using information theory.

Framework

Expected Information Gain

Given board $S \in \mathcal{S}$ and question $q$ with answer $a \in \mathcal{A}$:
$\text{IG}(S;\, a) \;=\; H(S) \;-\; H(S \mid a)$ information gain
$\text{EIG}(S;\, q) \;=\; \mathbb{E}_{a}\!\big[\text{IG}(S;\, a)\big]$ expectation over answer
$\phantom{\text{EIG}(S;\, q)} \;=\; H_b(p)$ when $\mathcal{A} = \{0, 1\}$
where $p := P(a\!=\!1)$
$S$
$q$
“Is the purple ship vertical?”
$a$
Yes No
Let's build up EIG from standard information theory. S is a random variable over board states — here's one partial board the Captain might see. The Captain asks a question q, like "is the purple ship vertical?", and gets a yes/no answer. Information Gain measures how much one answer reduces uncertainty. EIG averages over possible answers — it's mutual information. For binary answers, this simplifies to binary entropy, maximized at p = 0.5.
Framework

Properties of EIG

$\text{EIG}(S;\, q) = H_b(p)$
Assumes a perfect Spotter
Spotter as a BSC with noise $\varepsilon$:
$\text{EIG}_\varepsilon(S;\, q) = H_b\!\big(\varepsilon + (1\!-\!2\varepsilon)\,p\big) - H_b(\varepsilon)$
Here's the key intuition: EIG is maximized when p = 0.5 — when we're most uncertain about the answer. Questions where we already know the answer (p near 0 or 1) have low EIG. In our setting, the Spotter can make occasional mistakes, modeled as a binary symmetric channel with noise rate epsilon. This reduces the maximum achievable information, but questions with p near 0.5 are still optimal.
Framework

How do we estimate EIG?

$p \;:=\; P(a\!=\!1) \;=\; \underbrace{\mathbb{E}_{s \,\sim\, P(S)}}_{\text{board space}} \!\Big[\;\underbrace{P(a \mid q;\, s)}_{\text{semantics}}\;\Big]$
  Challenge 1: The space of possible boards is very large — marginalization over $P(S)$ is intractable
  Challenge 2: Evaluating $P(a \mid q;\, s)$ requires interpreting the semantics of natural language
We need to compute p — the probability that question q gets answer a=1. Expanding this, we need to marginalize over the board space P(S) and evaluate the conditional P(a|q;s) for each board. Two key challenges: first, the board space is combinatorially large, making exact marginalization intractable. Second, evaluating P(a|q;s) requires interpreting what the natural language question actually means with respect to the board.

Key idea: Translating to code grounds the answer in the actual board state, avoiding hallucination and misinterpretation.


def answer(true_board, partial_board) -> bool:
    # Columns 1-4 = zero-based indices 0-3
    max_allowed_col = 3
    ship_ids = [s for s in np.unique(true_board) if s > 0]

    count_within = 0
    for sid in ship_ids:
        cols = np.where(true_board == sid)[1]
        if cols.size > 0 and cols.max() <= max_allowed_col:
            count_within += 1

    return count_within >= 2

# >>> answer(true_board, partial_board)
# True
We saw earlier how questions get translated to code to compute EIG. The same pipeline is used by the Spotter to answer questions accurately. Here's a more complex example: the Captain asks whether at least two ships are in columns 1-4. The Spotter translates this into Python, executes it against the true board, and returns Yes. This code grounding avoids hallucination and misinterpretation.
Method

Monte Carlo inference with a world model

Sample plausible boards consistent with observations, then marginalize to get a tile-level belief.

Before I show the strategies, here's the key building block: a world model. We sample plausible board configurations consistent with everything observed so far, using Sequential Monte Carlo. Marginalizing over these samples gives us a belief state.
